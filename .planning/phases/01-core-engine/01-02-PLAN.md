    1. Create `Sources/BJSCore/Strategy/DealerProbability.swift`:

       This computes the probability distribution over dealer final outcomes {17, 18, 19, 20, 21, bust} for each dealer upcard (2 through Ace) under infinite-deck assumption.

       Use recursive computation with memoization. The dealer draws according to fixed rules:
       - Hit on any total < 17
       - For S17: stand on all 17s (including soft 17)
       - For H17: hit on soft 17, stand on hard 17 and soft 18+

       Key structure:
       ```swift
       struct DealerOutcome: Sendable {
           // Probabilities indexed as: [0]=17, [1]=18, [2]=19, [3]=20, [4]=21, [5]=bust
           let probabilities: [Double]  // Always sums to 1.0

           var bustProbability: Double { probabilities[5] }
           func probability(of total: Int) -> Double {
               guard (17...21).contains(total) else { return 0 }
               return probabilities[total - 17]
           }
       }

       enum DealerProbability {
           static func outcomes(upcard: Rank, dealerHitsSoft17: Bool) -> DealerOutcome
       }
       ```

       Implementation approach:
       - Infinite deck means each card drawn has probability: 1/13 for ranks 2-9 and Ace, 4/13 for 10-value cards (10, J, Q, K combined)
       - Recursively compute from each dealer state (total, isSoft):
         - If total > 21: bust
         - If total >= 17 (and not soft 17 when H17): stand at current total
         - If total == 17 and isSoft and dealerHitsSoft17: continue hitting
         - Otherwise: hit -- for each possible next card value, multiply probability by recursive result and sum
       - Memoize by (total, isSoft, dealerHitsSoft17) key

       The upcard starts the recursion: compute dealer's initial state from the upcard, then recursively resolve.

       Handle the ace upcard specially: dealer checks for blackjack under American peek (but this affects strategy, not the probability distribution itself -- the probability distribution is for non-blackjack hands).

    2. Create `Sources/BJSCore/Strategy/StrategyTable.swift` per D-04:
       ```swift
       struct StrategyTable: Sendable {
           // hardTotals[playerTotal - 5][dealerUpcard.columnIndex]
           let hardTotals: [[Action]]   // 17 rows x 10 columns

           // softTotals[playerTotal - 13][dealerUpcard.columnIndex]
           let softTotals: [[Action]]   // 9 rows x 10 columns

           // pairs[pairRankIndex][dealerUpcard.columnIndex]
           // pairRankIndex: 2s=0, 3s=1, ..., 10s=8, As=9
           let pairs: [[Action]]        // 10 rows x 10 columns

           func action(for hand: BlackjackHand, dealerUpcard: Rank, rules: BlackjackRules) -> Action {
               if hand.isPair && hand.canSplit(rules: rules, currentSplitCount: 0) {
                   let pairAction = pairs[hand.pairIndex][dealerUpcard.columnIndex]
                   if pairAction == .split { return .split }
                   // If pair table says don't split, fall through to hard/soft
               }
               if hand.isSoft {
                   return softTotals[hand.softIndex][dealerUpcard.columnIndex]
               }
               return hardTotals[hand.hardIndex][dealerUpcard.columnIndex]
           }
       }
       ```

    3. Create `Sources/BJSCore/Strategy/StrategyEngine.swift` per D-02, D-03:
       ```swift
       final class StrategyEngine: @unchecked Sendable {
           private var cache: [BlackjackRules: StrategyTable] = [:]
           private let lock = NSLock()

           func strategy(for rules: BlackjackRules) -> StrategyTable {
               lock.lock()
               defer { lock.unlock() }
               if let cached = cache[rules] { return cached }
               let table = generateTable(for: rules)
               cache[rules] = table
               return table
           }

           private func generateTable(for rules: BlackjackRules) -> StrategyTable
       }
       ```

       The `generateTable` method must:
       a. Compute dealer probability distributions for each upcard (2-Ace) using `DealerProbability.outcomes(upcard:dealerHitsSoft17:)`
       b. For each cell in hardTotals (player total 5-21 x dealer 2-A):
          - Compute EV(Stand): compare player total against dealer outcome distribution
          - Compute EV(Hit): recursively compute EV of all possible next-card draws
          - Compute EV(Double): if eligible, 2x EV of hitting exactly once then standing
          - Compute EV(Surrender): if eligible, always -0.5
          - Select action with highest EV
       c. For each cell in softTotals (soft 13-21 x dealer 2-A): same computation
       d. For each cell in pairs (pair 2s-As x dealer 2-A):
          - Compute EV(Split): approximately 2x EV of playing a single hand starting with one card of the pair rank. For split aces: typically only one card dealt per hand (unless hitSplitAces is true).
          - Compare against EV of best non-split action
          - If EV(Split) > best non-split EV, recommend Split; otherwise recommend the non-split best action
       e. For ENHC (peekRule == .europeanNoPeek): when computing EV(Double) and EV(Split) against dealer 10 or Ace, account for the risk of losing the extra bet to a dealer natural. The probability of dealer blackjack given upcard Ace is 4/13; given upcard 10-value is 1/13.

       **Infinite deck assumption** is used throughout (per RESEARCH.md recommendation): each card drawn has fixed probability independent of cards already dealt. This produces correct total-dependent basic strategy.
