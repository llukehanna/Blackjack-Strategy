# 02.2-01 — Design Token Expansion

## Objective

Expand the design token system so that every visual value required by MASTER.md has a named Swift constant. After this plan, no component should need to introduce a raw literal for corner radius, shadow, animation timing, or feedback color. Typography and StatsBarView are updated to use monospaced stat values.

## Files Changed

| File | Action | Description |
|------|--------|-------------|
| `BJS/Design/CornerRadius.swift` | CREATE | Named corner radius constants |
| `BJS/Design/Elevation.swift` | CREATE | Card shadow constants |
| `BJS/Design/AnimationTiming.swift` | CREATE | Animation duration constants |
| `BJS/Design/BJSColors.swift` | UPDATE | Add feedbackCorrectBackground, feedbackIncorrectBackground, cardFaceDown |
| `BJS/Design/Typography.swift` | UPDATE | Add statValue (monospacedDigit) |
| `BJS/Views/Common/StatsBarView.swift` | UPDATE | Use Typography.statValue and Typography tokens; remove raw font literals |

### Task 5: Update Typography.swift

Add `statValue` — monospaced digits for all numeric stat displays:

```swift
import SwiftUI

enum Typography {
    static let title: Font = .title2.bold()
    static let section: Font = .subheadline
    static let body: Font = .body
    static let secondary: Font = .subheadline
    static let mono: Font = .title2.monospaced().bold()
    static let buttonLabel: Font = .body.bold()
    /// Numeric stat values — monospaced digits for visual alignment
    static let statValue: Font = .title3.monospacedDigit().bold()
}
```

Note: `statValue` uses `.title3` (slightly smaller than `.title2`) — appropriate for compact stat chips. Use `.title2.monospacedDigit().bold()` for larger stat cards in SessionSummaryView if needed. If uniform size is preferred, adjust both to `.title2`.

### Task 6: Update StatsBarView.swift

Replace raw font literals with `Typography` tokens. Use `Typography.statValue` for stat numbers:

```swift
import SwiftUI

struct StatsBarView: View {
    let stats: SessionStats

    var body: some View {
        HStack(spacing: 0) {
            statChip(value: "\(Int(stats.accuracy))%", label: "Accuracy")
            thinDivider
            statChip(value: "\(stats.handCount)", label: "Hands")
            thinDivider
            statChip(value: "\(stats.errorCount)", label: "Errors")
        }
        .padding(.vertical, Spacing.sm)
        .frame(maxWidth: .infinity)
        .background(Color(.secondarySystemBackground))
        .overlay(alignment: .bottom) {
            Rectangle()
                .fill(Color(.separator))
                .frame(height: 0.5)
        }
    }

    private func statChip(value: String, label: String) -> some View {
        VStack(spacing: Spacing.xs) {
            Text(value)
                .font(Typography.statValue)
            Text(label)
                .font(Typography.secondary)
                .foregroundStyle(.secondary)
        }
        .frame(maxWidth: .infinity)
    }

    private var thinDivider: some View {
        Rectangle()
            .fill(Color(.separator))
            .frame(width: 0.5, height: 24)
    }
}
```

Changes:
- `.body.bold()` → `Typography.statValue` (monospaced digits)
- `.caption` → `Typography.secondary` (consistent with token system)
- `VStack(spacing: 2)` → `VStack(spacing: Spacing.xs)` (token: 4pt)
