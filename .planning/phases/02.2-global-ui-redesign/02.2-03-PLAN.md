## Tasks

### Task 1: Update SessionSummaryView

Three changes:

**1a. Monospaced stat values (V-02)**
In `statCard()`, change the value `Text`:
- `Typography.title` → `Typography.statValue` (monospaced digits, title3-sized)

**1b. CornerRadius token on stat cards**
- `cornerRadius: 8` → `CornerRadius.statCard`

**1c. Subtle mistake log row treatment**
Give each mistake row a minimal visual separator — a thin bottom border using `.separator` color, consistent with MASTER.md's "balanced density" principle. This helps scanability without adding clutter.

Updated `statCard()`:
```swift
@ViewBuilder
private func statCard(label: String, value: String) -> some View {
    VStack(spacing: Spacing.xs) {
        Text(label)
            .font(Typography.secondary)
            .foregroundStyle(.secondary)
        Text(value)
            .font(Typography.statValue)
    }
    .frame(maxWidth: .infinity)
    .padding(.vertical, Spacing.md)
    .background(
        RoundedRectangle(cornerRadius: CornerRadius.statCard)
            .fill(Color(.secondarySystemBackground))
    )
}
```

Updated mistake log rows:

### Task 2: Evaluate SectionContainerView surface

MASTER.md allows "light glass-like surfaces only where needed — slight blur + translucency — extremely subtle — to separate layers and add depth."

Current state: `SectionContainerView` has no background. It renders content with padding on the `systemGroupedBackground`.

Decision: Add a subtle `.secondarySystemBackground` fill so that sections visually "float" above the grouped background — creates the light layering MASTER.md describes without being heavy.

This is consistent with how iOS Settings, Apple Health, and Apple Sports present grouped list content.

Updated `SectionContainerView`:
```swift
import SwiftUI

struct SectionContainerView<Content: View>: View {
    let content: Content

    init(@ViewBuilder content: () -> Content) {
        self.content = content()
    }

    var body: some View {
        VStack(alignment: .leading, spacing: Spacing.sm) {
            content
        }
        .padding(.horizontal, Spacing.md)
        .padding(.vertical, Spacing.md)
        .frame(maxWidth: .infinity, alignment: .leading)
        .background(Color(.secondarySystemBackground))
    }
}
```

Note: With this change, `SessionStartView` should remove the `Divider()` calls between sections — the background separation replaces the dividers as the visual separator between sections. Evaluate whether padding between sections (e.g., `Spacing.xs` gap) reads better than dividers.

Update `SessionStartView` accordingly:
- Replace `Divider()` between sections with a `Spacing.xs` or `Spacing.sm` gap, OR keep dividers and remove background (choose based on visual result)
- Recommended: remove `Divider()` calls; add `VStack(spacing: 1)` between sections so a 1pt gap acts as a natural separator (matches iOS grouped table behavior)

Revised `SessionStartView` VStack structure:
```swift

    SectionContainerView { /* Mode */ }
    SectionContainerView { /* Casino Preset */ }
    SectionContainerView { /* Rules */ }
```
