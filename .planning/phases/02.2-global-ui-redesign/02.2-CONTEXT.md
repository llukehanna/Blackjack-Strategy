# Phase 02.2 — Global UI Redesign

## Goal

Refactor the entire visible UI to conform tightly to `design-system/bjs/MASTER.md`. Every screen and shared component must feel premium, polished, and production-quality — consistent with the "Apple Sports / Vercel / Raycast translated into a native iOS training app" benchmark.

This is a **refinement/redesign phase only**. No new product features. No blackjack logic changes.

---

## Design Authority

`design-system/bjs/MASTER.md` is the authoritative contract for this phase.

Key directives from MASTER.md:
- Premium, minimal, analytical, calm — NOT casino, playful, gamified, or flashy
- Muted feedback colors (not vivid green/red flashes)
- Feedback as soft highlights, not full-screen overlays
- Stats use monospaced digits
- Two rows of action buttons (primary / secondary hierarchy)
- Subtle layering via background separation and light translucency
- No bright colors; no gradients; no neon/glow
- Animations: minimal, fast (150–200ms), functional only
- Strict safe-area compliance on iPhone SE through iPhone 16

## Design Decisions

### DD-01: FeedbackOverlay Redesign

Replace full-screen ZStack overlay with a compact, self-sizing banner anchored to the top of the play area.

- Small pill/banner with muted background tint
- SF Symbol icon (checkmark.circle.fill / xmark.circle.fill) + message text
- Positioned `.top` inside the `.overlay`
- Transition: `.move(edge: .top).combined(with: .opacity)`
- Duration: `AnimationTiming.feedbackFade` (0.15s)
- Background: `BJSColors.feedbackCorrectBackground` / `BJSColors.feedbackIncorrectBackground`
- Does NOT cover card area — cards remain visible during feedback

### DD-02: Action Button Two-Row Layout

Split `availableActions` into primary (Hit, Stand) and secondary (Double, Split, Surrender) groups.

```
[ Hit ] [ Stand ]               ← primary row — filled accent
[ Double ] [ Split ] [ Surrender ] ← secondary row — muted/outlined
```

Both rows use equal-flex distribution within their row. If only primary actions are available (no double/split/surrender), only the primary row renders. Secondary row is omitted when empty.

### DD-03: Typography.statValue

Add `statValue: Font = .title2.monospacedDigit().bold()` to `Typography`.
- Use in: `StatsBarView` value labels, `SessionSummaryView` stat card values
- `.monospacedDigit()` makes numeric characters monospaced without affecting letters

### DD-04: Card Face-Down Color

Replace `Color.blue.opacity(0.8)` with `BJSColors.cardFaceDown` — a brand-adjacent slate color:
- Light mode: dark slate (`#1C2B3A`) — same family as accent
- Dark mode: muted light slate (`#8FA3B4`) — visible on dark background
- Ties card backs to brand palette; removes arbitrary blue

### DD-05: Feedback Colors (Muted)

```swift
BJSColors.feedbackCorrectBackground  = Color.green.opacity(0.10)
BJSColors.feedbackIncorrectBackground = Color.red.opacity(0.10)
```

Paired with SF Symbol tinted `.systemGreen` / `.systemRed` for icon emphasis without background saturation.

### DD-06: CornerRadius Token

```swift
enum CornerRadius {
    static let card: CGFloat = 8
    static let button: CGFloat = 8
    static let statCard: CGFloat = 8
    static let banner: CGFloat = 10
}
```

### DD-07: Elevation Token

```swift
enum Elevation {
    static let cardShadowOpacity: Double = 0.12
    static let cardShadowRadius: CGFloat = 4
    static let cardShadowY: CGFloat = 2
}
```

### DD-08: AnimationTiming Token

```swift
enum AnimationTiming {
    static let feedbackFade: Double = 0.15
    static let feedbackHold: Double = 1.0
    static let dealerPlayOut: Double = 0.3
    static let handResultHold: Double = 1.0
}
```
