# 02.2-04 — Visual Verification & Human Approval Gate

## Objective

Verify the full redesign visually and functionally. Capture screenshots across required device/mode combinations. Confirm all MASTER.md violations are resolved. Gate progression to Phase 3 on explicit human approval.

## Verification Matrix

| Screen | iPhone 16 Light | iPhone 16 Dark | iPhone SE Light |
|--------|:--------------:|:--------------:|:---------------:|
| SessionStartView | required | required | required |
| TrainerView (awaitingDecision) | required | required | required |
| TrainerView (feedback visible) | required | — | — |
| SessionSummaryView | required | required | — |

Minimum: 9 screenshots total.

## Tasks

### Task 1: Build & Test

```bash
# Build
xcodebuild -project BJS.xcodeproj -scheme BJS -destination 'platform=iOS Simulator,name=iPhone 16' build

# Tests
xcodebuild test -project BJS.xcodeproj -scheme BJS -destination 'platform=iOS Simulator,name=iPhone 16'
```

Pass criteria:
- [ ] Build: 0 errors, 0 warnings introduced by this phase
- [ ] Tests: all pass

### Task 2: Screenshot Capture — iPhone 16

Launch on iPhone 16 simulator (light mode):
1. Navigate to Practice tab → capture `SessionStartView`
2. Tap "Start Session" → capture `TrainerView` in `awaitingDecision` state (cards dealt, buttons visible)
3. Make a decision (e.g., tap Hit) → capture feedback banner visible
4. Complete session (tap "End Session" → End) → capture `SessionSummaryView`

Switch to dark mode (Settings → Display & Brightness → Dark):
5. Capture `SessionStartView`
6. Capture `TrainerView` (awaitingDecision)
7. Capture `SessionSummaryView`

### Task 3: Screenshot Capture — iPhone SE

Launch on iPhone SE (3rd gen) simulator (light mode):
8. Capture `SessionStartView`
9. Capture `TrainerView` (awaitingDecision) — verify no tab bar overlap, no button clipping

### Task 4: MASTER.md Compliance Checklist

For each captured screenshot, confirm:

**V-01 FeedbackOverlay:**
- [ ] Feedback is a compact banner at top of play area — NOT a full-screen color flash
- [ ] Cards remain visible while feedback banner is shown
- [ ] Color is muted tint, not vivid green/red

**V-02 Monospaced Stats:**
- [ ] StatsBarView accuracy/hands/errors values are monospaced digits
- [ ] SessionSummaryView stat card values are monospaced digits

**V-03 Two-row Buttons:**
- [ ] TrainerView shows Hit/Stand on primary row, Double/Split/Surrender on secondary row
- [ ] Visual hierarchy is clear (primary = filled accent, secondary = muted)

**V-04 Card Face-down:**
- [ ] Face-down card shows slate color (not bright blue) in light mode
- [ ] Face-down card shows appropriately contrasted slate in dark mode

**General MASTER.md:**
- [ ] No bright/vivid colors used anywhere outside feedback
- [ ] No gradients visible on any screen
- [ ] Layout is clean, aligned, no clutter
- [ ] Hierarchy is obvious at a glance
- [ ] No overlap or clipping on iPhone SE (check action buttons, End Session button, tab bar)
- [ ] SectionContainerView shows subtle surface separation in SessionStartView
- [ ] App feels premium, not casino-themed or gamified

### Task 5: Token Completeness Check

```bash
# Verify no raw color literals remain in Design files or Views
grep -r "Color\." BJS/Views/ --include="*.swift" | grep -v "BJSColors\|\.primary\|\.secondary\|\.white\|\.red\|\.green\|systemBackground\|systemGray\|separator\|systemGreen\|systemRed\|label"

# Verify no raw cornerRadius literals remain in Views
grep -r "cornerRadius:" BJS/Views/ --include="*.swift" | grep -v "CornerRadius\."

# Verify no raw shadow literals remain in Views
grep -r "\.shadow(" BJS/Views/ --include="*.swift" | grep -v "Elevation\."
```

Each grep should return clean (no unexpected raw literals).
