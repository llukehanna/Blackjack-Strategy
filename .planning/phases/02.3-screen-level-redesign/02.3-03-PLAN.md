# 02.3-03 — SessionSummaryView Redesign

## Objective

Replace the 2×2 stat grid with a dominant accuracy hero (72pt), collapse supporting stats into a single tertiary annotation line, and restructure the mistakes section as compact secondary detail. Home becomes a plain text link.

## Tasks

### Task 1: Rewrite SessionSummaryView

Full replacement of `BJS/Views/Trainer/SessionSummaryView.swift`:

```swift
import SwiftUI

struct SessionSummaryView: View {
    let stats: SessionStats
    let mistakes: [DecisionRecord]
    let onPlayAgain: () -> Void
    let onHome: () -> Void

    var body: some View {
        ScrollView {
            VStack(alignment: .leading, spacing: 0) {

                // ── HERO BLOCK ────────────────────────────────
                VStack(spacing: 0) {
                    Spacer().frame(height: Spacing.lg)

                    Text("SESSION COMPLETE")
                        .font(.caption.bold())
                        .foregroundStyle(.secondary)
                        .tracking(1.2)
                        .frame(maxWidth: .infinity, alignment: .center)

                    Spacer().frame(height: Spacing.xs)

                    Text("\(Int(stats.accuracy))%")
                        .font(Typography.heroStat)
                        .foregroundStyle(.primary)
                        .frame(maxWidth: .infinity, alignment: .center)

                    Spacer().frame(height: Spacing.xs)

                    Text(supportingStatsLine)
                        .font(.caption.monospacedDigit())
                        .foregroundStyle(.tertiary)
                        .frame(maxWidth: .infinity, alignment: .center)

                    Spacer().frame(height: Spacing.xl)
                }

                // ── SEPARATOR ─────────────────────────────────
                Divider()

                // ── MISTAKES SECTION ─────────────────────────
                Spacer().frame(height: Spacing.md)

                HStack {
                    Text("MISTAKES")
                        .font(.caption.bold())
                        .foregroundStyle(.tertiary)
                        .tracking(1.2)
                    Spacer()
                    if !mistakes.isEmpty {
                        Text("\(mistakes.count)")
                            .font(.caption.bold())
                            .foregroundStyle(.tertiary)
                    }
                }
                .padding(.horizontal, Spacing.md)

                Spacer().frame(height: Spacing.sm)

                if mistakes.isEmpty {
                    Text("No mistakes.")
                        .font(.caption)
                        .foregroundStyle(.tertiary)
                        .padding(.horizontal, Spacing.md)
                } else {
                    ForEach(Array(mistakes.enumerated()), id: \.offset) { index, record in
                        VStack(alignment: .leading, spacing: Spacing.xs) {
                            Text(record.handDescription)
                                .font(.subheadline)
                                .foregroundStyle(.primary)

                            HStack(spacing: Spacing.xs) {
                                Text(record.playerAction.rawValue.capitalized)
                                    .font(.caption)
                                    .foregroundStyle(Color(.systemRed).opacity(0.7))
                                Text("→")
                                    .font(.caption)
                                    .foregroundStyle(.secondary)
                                Text(record.correctAction.rawValue.capitalized)
                                    .font(.caption)
                                    .foregroundStyle(.primary)
                            }
                        }
                        .padding(.vertical, Spacing.xs)
                        .padding(.horizontal, Spacing.md)

                        if index < mistakes.count - 1 {
                            Divider()
                                .padding(.leading, Spacing.md)
                        }
                    }
                }

                Spacer().frame(height: Spacing.xl)

                // ── CTA BLOCK ─────────────────────────────────
                Spacer(minLength: Spacing.lg)

                Button {
                    onPlayAgain()
                } label: {
                    Text("Play Again")
                        .font(.headline.bold())
                        .foregroundStyle(.white)
                        .frame(maxWidth: .infinity)
                        .frame(height: 52)
                        .background(BJSColors.accent)
                        .clipShape(RoundedRectangle(cornerRadius: CornerRadius.button))
                }
                .buttonStyle(.plain)
                .padding(.horizontal, Spacing.md)

                Spacer().frame(height: Spacing.sm)

                Button {
                    onHome()
                } label: {
                    Text("Home")
                        .font(.subheadline)
                        .foregroundStyle(.secondary)
                        .frame(maxWidth: .infinity, alignment: .center)
                }
                .buttonStyle(.plain)

                Spacer().frame(height: Spacing.md)
            }
        }
        .background(Color(.systemGroupedBackground))
    }

    // MARK: - Helpers

    private var supportingStatsLine: String {
        "\(stats.handCount) hands\u{B7}\(stats.errorCount) error\(stats.errorCount == 1 ? "" : "s")\u{B7}\(stats.bestStreak) best"
    }
}
```

**Implementation notes:**

- `Typography.heroStat` = `.system(size: 72, weight: .bold, design: .monospaced)` — added in Plan 01. The 72pt number is the first large element the eye hits after the SESSION COMPLETE label.

- Supporting stats use `.caption.monospacedDigit()` + `.tertiary` foreground. `.tertiary` is approximately 30% opacity in light mode — visibly subordinate to `.secondary`. The line reads as annotation, not content.

- `supportingStatsLine` uses `\u{B7}` (middle dot ·) as separator with no spaces — `"14 hands·1 error·3 best"`. Tight, compact, not verbose.

- The `Spacer(minLength: Spacing.lg)` before the CTA block allows the CTA to flex toward the bottom on taller devices while maintaining a minimum gap on SE. Combined with the `Spacer().frame(height: Spacing.xl)` above it, the mistakes section and CTA are separated by at least `Spacing.xl + Spacing.lg` = 56pt.

- Mistake row format: `handDescription` on line 1 (`.subheadline .primary`), then `playerAction → correctAction` on line 2 (`.caption`, wrong action in `Color(.systemRed).opacity(0.7)`, arrow in `.secondary`, correct action in `.primary`).

- Inset `Divider()` between mistake rows uses `.padding(.leading, Spacing.md)` — not full-width, which would look like a structural separator. Inset reads as a row separator within a list.

- The `statCard()` private function is removed entirely — no 2×2 grid.

- "Home" is a `Button` with `.plain` style and `.subheadline .secondary` — no frame, no border, no background. It is visually a text link.
