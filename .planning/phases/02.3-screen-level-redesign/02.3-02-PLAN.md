# 02.3-02 — TrainerView + StatsBarView Redesign

## Objective

Redesign the StatsBarView to a 42pt structured strip and restructure the TrainerView play field into two explicitly labeled zones (DEALER / YOU) with the player total as the dominant number. Redesign the action dock with precise height hierarchy and correct spacing ratios.

## Tasks

### Task 1: Rewrite StatsBarView

42pt total strip height. `systemGray6` background. Value + label on same horizontal line per chip (not stacked). Three chips separated by 0.5pt hairlines.

```swift
import SwiftUI

struct StatsBarView: View {
    let stats: SessionStats

    var body: some View {
        HStack(spacing: 0) {
            statChip(value: "\(Int(stats.accuracy))%", label: "Acc")
            hairline
            statChip(value: "\(stats.handCount)", label: "Hands")
            hairline
            statChip(value: "\(stats.errorCount)", label: "Errs")
        }
        .frame(maxWidth: .infinity)
        .frame(height: 42)
        .background(Color(.systemGray6))
        .overlay(alignment: .bottom) {
            Rectangle()
                .fill(Color(.separator))
                .frame(height: 0.5)
        }
    }

    private func statChip(value: String, label: String) -> some View {
        HStack(spacing: Spacing.xs) {
            Text(value)
                .font(Typography.statValue)
                .foregroundStyle(.primary)
            Text(label)
                .font(Typography.secondary)
                .foregroundStyle(.secondary)
        }
        .frame(maxWidth: .infinity)
    }

    private var hairline: some View {
        Rectangle()
            .fill(Color(.separator))
            .frame(width: 0.5, height: 24)
    }
}
```

Changes from current StatsBarView:
- Background: `secondarySystemBackground` → `systemGray6` (more subtle, less interrupting)
- Layout: VStack per chip → HStack per chip (value + label inline)
- Height: ~38pt implicit → explicit `frame(height: 42)`
- Labels: "Accuracy" → "Acc", "Errors" → "Errs" (shorter to prevent truncation on SE)
- Spacing: `VStack(spacing: Spacing.xs)` → `HStack(spacing: Spacing.xs)`

### Task 2: Rewrite TrainerView playArea

Replace the current `playArea` computed property. The outer `TrainerView.body` structure (navigation, toolbar, sheet, alert, onChange handlers) remains unchanged. Only the `playArea` and the `shouldRevealDealerHole` helper change.

New `playArea`:

```swift
@ViewBuilder
private var playArea: some View {
    VStack(spacing: 0) {

        // ── DEALER ZONE ──────────────────────────────
        Spacer().frame(height: Spacing.lg)

        zoneLabel("DEALER")

        Spacer().frame(height: Spacing.sm)

        if let dealerHand = viewModel.dealerHand {
            let faceDownIndices: Set<Int> = shouldRevealDealerHole ? [] : [1]
            HandView(cards: dealerHand.cards, faceDownIndices: faceDownIndices)
        }

        Spacer().frame(height: Spacing.xl)   // larger below = top-weighted

        // ── PLAYER ZONE ───────────────────────────────
        if let playerHand = viewModel.playerHand {
            HStack(alignment: .firstTextBaseline) {
                zoneLabel("YOU")
                Spacer()
                Text("\(playerHand.total)")
                    .font(Typography.playerTotal)
                    .foregroundStyle(.primary)
            }
            .padding(.horizontal, Spacing.md)

            Spacer().frame(height: Spacing.sm)

            HandView(cards: playerHand.cards)
        }

        // Hand result label (showingResult phase)
        if viewModel.phase == .showingResult, let result = viewModel.handResult {
            Text(result.rawValue)
                .font(Typography.title)
                .padding(.top, Spacing.sm)
        }

        // Learn mode hint
        if let correctAction = viewModel.correctActionForDisplay {
            Text("Correct play: \(correctAction.rawValue.capitalized)")
                .font(Typography.section.bold())
                .foregroundStyle(.secondary)
                .padding(.top, Spacing.sm)
        }

        Spacer().frame(height: Spacing.lg)

        // ── ACTION DOCK ───────────────────────────────
        Divider()

        Spacer().frame(height: Spacing.md)

        ActionButtonsView(
            availableActions: viewModel.availableActions,
            isEnabled: viewModel.phase == .awaitingDecision,
            onAction: { action in viewModel.playerAction(action) }
        )

        Spacer().frame(height: Spacing.md)

        Button("End Session") {
            showEndSessionAlert = true
        }
        .font(.subheadline)
        .foregroundStyle(.secondary)
        .buttonStyle(.plain)

        Spacer().frame(height: Spacing.md)
    }
    .overlay {
        if let feedback = viewModel.feedbackState {
            FeedbackOverlayView(feedback: feedback)
                .animation(.easeInOut(duration: AnimationTiming.feedbackFade), value: viewModel.feedbackState != nil)
        }
    }
}

private func zoneLabel(_ text: String) -> some View {
    Text(text)
        .font(.caption.bold())
        .foregroundStyle(.secondary)
        .tracking(1.2)
        .frame(maxWidth: .infinity, alignment: .leading)
        .padding(.horizontal, Spacing.md)
}
```

**Implementation notes:**

- `zoneLabel()` is a private helper that creates the ALL-CAPS secondary label used for DEALER and YOU zones. The YOU usage overrides alignment via the outer HStack — `zoneLabel("YOU")` provides the leading text, then `Spacer()` + total pushes the total to the right.

- The `Spacer().frame(height:)` pattern (fixed height spacers) keeps the spacing deterministic rather than flexible. This is intentional — the play area should have consistent rhythm, not floating elements.

- Top-weighting: `Spacer().frame(height: Spacing.lg)` above dealer (24pt) vs `Spacer().frame(height: Spacing.xl)` below dealer (32pt). The 8pt delta shifts the visual center of gravity upward.

- The separator (`Divider()`) above the action dock is the only horizontal rule in the play area. It marks the functional boundary between observation and action.

- `Spacing.smd` does not appear anywhere. All spacers use xs/sm/md/lg/xl.

- The standalone `Text("Total: \(playerHand.total)")` line is removed. The total now appears in the YOU zone header row.

- The `ActionButtonsView` is unchanged from 02.2 — it already implements the two-row primary/secondary layout. The spacing change between rows is already `Spacing.md` between and `Spacing.sm` within from 02.2-02.
