# Phase 02.3 — Screen-Level Redesign

## Goal

Materially redesign the three primary screens at the layout and composition level. Phase 02.2 cleaned the token system. Phase 02.3 changes how the screens actually look and feel. The result must be visibly different from what shipped in Phase 02.2 — not a restyling pass.

This is a redesign/refinement phase only. No new product features. No blackjack logic changes.

---

## Design Authority

`design-system/bjs/MASTER.md` is the authoritative style contract.

Approved design direction: **Apple Sports / Vercel / Raycast** translated into a native iOS training utility.

Must feel: premium · minimal · analytical · calm · deliberate · fast
Must not feel: casino-themed · playful · gamified · web-marketing styled

---

## Spacing Vocabulary

**Strict:** xs(4) / sm(8) / md(16) / lg(24) / xl(32) only.
`Spacing.smd` (12pt) is **not used** anywhere in Phase 02.3.

---

## New Typography Tokens Required

Two new tokens must be added to `Typography.swift` before screen work begins:

```swift
/// 72pt display size for hero stat (session accuracy %)
static let heroStat: Font = .system(size: 72, weight: .bold, design: .monospaced)

/// 34pt for player hand total in TrainerView
static let playerTotal: Font = .system(size: 34, weight: .bold, design: .monospaced)
```

These replace what would otherwise be raw `Font.system(size:weight:design:)` literals in the view layer.

---

## New Component Required

### TrainingModeToggle

A custom two-cell toggle to replace the default `Picker(.segmented)` for mode selection. The default segmented control is too generic.

```
┌──────────────────┬───────────────────┐
│                  │                   │
│      Learn       │       Test        │  height: 52pt
│                  │                   │  cornerRadius: 10pt
└──────────────────┴───────────────────┘
  selected cell: BJSColors.accent fill + .white .headline.bold()
  unselected cell: Color(.systemGray6) + .primary .headline
  shared outer border: 0.5pt Color(.separator) stroke
  cells share edge — no gap between them
```

File: `BJS/Views/Common/TrainingModeToggle.swift`

## Screen 2 — TrainerView + StatsBarView

### StatsBarView Redesign (42pt height)

```
Color(.systemGray6) background strip, 42pt total height
HStack(spacing: 0) of 3 chips, each maxWidth .infinity
Each chip:
  HStack(spacing: Spacing.xs) {
    Text(value).font(Typography.statValue)          // .subheadline.monospacedDigit().bold()
    Text(label).font(Typography.secondary).foregroundStyle(.secondary)
  }
  .frame(maxWidth: .infinity)
Chips separated by 0.5pt vertical hairline (Rectangle, width 0.5, height 24)
Spacing.sm (8pt) vertical padding top + bottom = 8+chip_height+8 = ~42pt total
```

Note: `.caption` for label → `.secondary` (Typography token). Value and label on the **same line**, not stacked.

### TrainerView Play Field

### "Total" label removal
The current `Text("Total: \(playerHand.total)")` is replaced by the YOU + total HStack row above. The standalone "Total:" label is removed entirely.

### Hand result label
`Text(result.rawValue)` shown during `.showingResult` phase stays, positioned within the player zone VStack after cards.

### Learn mode hint
`Text("Correct play: \(correctAction.rawValue.capitalized)")` stays, positioned before the action dock separator (above the separator, below player cards zone).

## Screen 3 — SessionSummaryView

### Structure

ScrollView with:
1. Hero block (top, vertically leading)
2. Single separator
3. Mistakes section
4. Spacer
5. CTA footer (pinned with spacer)

### Vertical Rhythm

```
Spacing.lg (24pt)         ← top-shifted: lg not xl — score appears high on screen

  SESSION COMPLETE        .caption.bold(), ALL-CAPS, .secondary, .tracking(1.2), centered

Spacing.xs (4pt)

              92%          Typography.heroStat (.system 72pt mono bold), .primary, centered

Spacing.xs (4pt)

  14 hands · 1 error · 3 best     .caption.monospacedDigit(), .tertiary, centered
                                   · separators in same style — no spaces around them

Spacing.xl (32pt)

──────────────────────────────────  0.5pt separator (only divider on this screen)

Spacing.md (16pt)

  MISTAKES               1         .caption.bold(), ALL-CAPS, .tertiary, leading LEFT
                                   count: .caption.bold(), .tertiary, trailing RIGHT
                                   HStack with Spacer between label and count

  [if mistakes.isEmpty:]
  Spacing.sm (8pt)
  No mistakes.                     .caption, .tertiary, leading

  [else:]
  Spacing.sm (8pt)
  ForEach(mistakes) { record in
    VStack(alignment: .leading, spacing: Spacing.xs) {
      Text(record.handDescription)      .subheadline, .primary
      HStack(spacing: Spacing.xs) {
        Text(record.playerAction.rawValue.capitalized)   Color(.systemRed).opacity(0.6)
        Text("→")                                         .secondary .caption
        Text(record.correctAction.rawValue.capitalized)  .primary .caption
      }
    }
    .padding(.vertical, Spacing.xs)

    if not last:
      Divider().padding(.leading, Spacing.md)   ← inset hairline, not full-width
  }

Spacing.xl (32pt)

  Spacer()                ← pushes CTAs to bottom

  ╔══════════════════════════════════════╗
  ║            Play Again                ║  52pt height, .headline.bold(), .white
  ╚══════════════════════════════════════╝  BJSColors.accent, cornerRadius 10pt
  Spacing.md horizontal inset

Spacing.sm (8pt)

  Home                    .subheadline, .secondary, centered, Button with plain style — no border

Spacing.md (16pt) + .safeAreaInset(edge: .bottom)
```

### Sizing relationships
- Hero (92%): 72pt — dominant, anchors screen
- SESSION COMPLETE label: `.caption` ~12pt — pure context
- Supporting stats: `.caption.tertiary` ~12pt — annotation layer
- Mistake scenario: `.subheadline` ~15pt — readable detail
- Mistake actions: `.caption` ~12pt — fine detail
- Play Again: `.headline.bold()` in 52pt button — only competing element, bottom-anchored

### What Gets Removed
- 2×2 stat grid entirely gone
- Bordered "Home" button — replaced with plain text
- `statCard()` helper method
