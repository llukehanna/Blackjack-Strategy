## Tasks

### Task 1: Build & Test

```bash
xcodebuild -project BJS.xcodeproj -scheme BJS \
  -destination 'platform=iOS Simulator,name=iPhone 16' \
  build 2>&1 | grep -E "error:|warning:|BUILD"

xcodebuild test -project BJS.xcodeproj -scheme BJS \
  -destination 'platform=iOS Simulator,name=iPhone 16' \
  2>&1 | grep -E "Test Suite|passed|failed|error"
```

Pass criteria:
- [ ] BUILD SUCCEEDED — 0 errors
- [ ] All tests pass

### Task 2: Screenshot Capture

Boot simulators and capture screenshots for all 3 screens × device/mode combinations.

```bash
# iPhone 16 — light mode
xcrun simctl boot "iPhone 16" 2>/dev/null || true
# [build + install app, launch, navigate, capture per screen]

# iPhone 16 — dark mode
xcrun simctl ui booted appearance dark
# [capture per screen]

# iPhone SE (3rd gen) — light mode
xcrun simctl boot "iPhone SE (3rd generation)" 2>/dev/null || true
xcrun simctl ui booted appearance light
# [capture SessionStartView and TrainerView — verify no clipping]
```

Save screenshots to `.planning/phases/02.3-screen-level-redesign/screenshots/`.

If simulator-based screenshots are not feasible, document compliance via code review checklist.

### Task 3: Spec Compliance Checklist

Verify each screen against the approved spec:

**SessionStartView:**
- [ ] MODE section label (ALL-CAPS .caption.bold()) appears above mode toggle
- [ ] Mode toggle is a custom two-cell component (not the system segmented control)
- [ ] Selected mode shows accent fill + white text; unselected shows systemGray6 + primary
- [ ] RULES section label appears above rules row
- [ ] Rules row shows preset name + rules summary + chevron as a single tappable card
- [ ] "Start Session" CTA is pinned below scroll content (never scrolls off screen)
- [ ] No old SectionContainerView sections, no Picker(.segmented), no "Edit Rules" link

**TrainerView:**
- [ ] Stats bar is 42pt height with systemGray6 background
- [ ] Stats bar shows value + label on same line per chip (not stacked)
- [ ] DEALER zone label appears above dealer cards, left-aligned
- [ ] YOU zone label appears left, player total appears right, same row
- [ ] Player total is visibly larger than all other text in the play field
- [ ] Dealer cards sit in upper portion of their zone (more space below than above)
- [ ] Single Divider separates play field from action dock
- [ ] Primary buttons (Hit/Stand) are taller than secondary buttons (Double/Split/Surrender)
- [ ] Gap between button rows is visibly larger than gap within each row
- [ ] End Session is plain text, no button frame

**SessionSummaryView:**
- [ ] Accuracy percentage renders at 72pt (visibly dominant)
- [ ] Supporting stats are clearly more muted than the accuracy number
- [ ] Single divider between hero block and mistakes section
- [ ] MISTAKES header is secondary weight (tertiary foreground)
- [ ] Wrong action in mistake rows has a red tint
- [ ] Play Again is a full-width filled accent button
- [ ] Home is plain text with no button styling

### Task 4: SE Clipping Check

On iPhone SE simulator:
- [ ] SessionStartView: "Start Session" button visible and not clipped
- [ ] TrainerView: Action buttons fully visible, not behind tab bar
- [ ] TrainerView: Both button rows visible without scrolling
- [ ] No content overflow under any condition

### Task 5: Token Compliance Check

```bash

  BJS/Views/Trainer/TrainerView.swift \
```

All greps should return clean (no unexpected output).
